Môn học: Introduction to Cloud Computing

Cloud Computing

Cloud computing represents a paradigm shift in how computing resources, data, and applications are delivered and managed. Instead of maintaining physical data centers or personal servers, users can access computing power, storage space, and software databases over the internet on a pay-as-you-go basis. This approach offers unparalleled flexibility, scalable resource allocation, dynamic workload management, high availability, cost efficiency, and robust security. Cloud services enable businesses and individual developers to rapidly innovate, test applications, and deploy global solutions without heavy upfront capital investments in hardware infrastructure.

Cloud Services

IaaS (Infrastructure as a Service)

Cung cấp tài nguyên hạ tầng thô (máy chủ ảo, mạng, lưu trữ). Khách hàng tự quản lý OS và ứng dụng.

Ví dụ: AWS EC2, Google Compute Engine.

PaaS (Platform as a Service)

Cung cấp môi trường để phát triển và triển khai ứng dụng mà không cần quản lý hạ tầng bên dưới.

Ví dụ: GitHub Pages, AWS Elastic Beanstalk.

SaaS (Software as a Service)

Cung cấp ứng dụng hoàn chỉnh qua internet, người dùng chỉ cần đăng nhập và sử dụng.

Ví dụ: Google Workspace, Microsoft 365, Gmail.
